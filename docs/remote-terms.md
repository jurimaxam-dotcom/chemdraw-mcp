# Terms of use for the hosted chempane connector

These terms apply to the free chemistry drawing service at https://mcp.chempane.com/mcp. You can use it to draw and explore chemical structures for study, research, and communication. Check the resolved structure and stereochemistry before relying on a drawing.

The hosted service limits request volume. Its availability and supported features may change. Report incorrect drawings or service problems through [project support](https://github.com/chempane/chempane/issues). For security issues, follow the [private reporting instructions](https://github.com/chempane/chempane/blob/main/SECURITY.md).

The [privacy policy](https://mcp.chempane.com/privacy) explains which inputs the service processes, when it looks up compound names, and how it handles technical request data. The [Apache-2.0 license](https://github.com/chempane/chempane/blob/main/LICENSE) covers the open-source software.
