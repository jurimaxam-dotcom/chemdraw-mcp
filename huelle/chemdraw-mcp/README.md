# chemdraw-mcp has been renamed to chempane

This package is now called **chempane**. Installing or upgrading `chemdraw-mcp`
installs chempane and keeps the old commands working (`chemdraw-mcp`,
`chemdraw-tool-server`, `chemdraw-install`, `chemdraw-doctor`), so existing
Claude Desktop configurations keep starting.

For new installations use the new name:

```bash
uv tool install chempane && chempane-install
```

Documentation: https://github.com/jurimaxam-dotcom/chemdraw-mcp

Unofficial, not affiliated with Revvity or ChemDraw.
